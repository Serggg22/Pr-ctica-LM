# Portfolio personal | Proyecto final 1º ASIR

Proyecto de concepto: sitio web personal con varias páginas, hecho con HTML, CSS y JavaScript sin librerías. Es una prueba de diseño y maquetación, por lo que algunas funciones son solo demostrativas.

## Contenido

- **Inicio:** galería de fotos con miniaturas y botones para avanzar y retroceder
- **Sobre mí:** presentación con reloj en tiempo real
- **CV:** currículum
- **Contacto:** formulario de contacto
- **Feedback:** formulario para dejar una opinión
- Todas las páginas están disponibles en **español e inglés**, con un botón para cambiar de idioma
- Menú adaptado a móvil

## Estructura

- `index.html`, `sobremi.html`, `cv.html`, `contacto.html`, `feedback.html`: páginas en español
- `indexen.html`, `aboutme.html`, `cven.html`, `contact.html`, `feedbacken.html`: páginas en inglés
- `Styles/`: hoja de estilos
- `JS/`: galería, reloj, menú móvil y validaciones
- `Fotos/`: imágenes

## Cómo verlo

Descarga el repositorio y abre `index.html` en el navegador. No necesita instalación.
